API Biblioteca

Projeto desenvolvido em TypeScript utilizando Node.js, Express e PostgreSQL (Supabase)

Funcionalidades
- Criar livro
- Listar livros
- Buscar livro por ISBN
- Atualizar livro
- Deletar livro

Tecnologias utilizadas
- TypeScript
- Node.js
- Express
- PostgreSQL
- Supabase

Estrutura do projeto
  src/
  ├── controllers
  ├── database
  ├── models
  ├── routes
  └── server.ts


Crie um arquivo .env na raiz do projeto:
DATABASE_URL=sua_url_do_supabase

#Como rodar o projeto

```bash
npm install
npm run dev
